조사·전수 탐색·다파일 리뷰·교차확인처럼 쪼갤 수 있는 일은 묻지 말고 서브에이전트를 병렬로 띄운다.

**Why:** 같은 조사를 순차·병렬로 실측해 보니 시간 차이는 1.3배 정도였다. 진짜 차이는 깊이였다 — 서브 하나가 한 조각에만 집중하니 놓치는 게 확 줄었다. 메인 세션 하나가 다 읽으면 컨텍스트가 부풀어 뒤쪽에서 실수가 늘었다.

**How to apply:**
- 영역별·관점별(버그/성능/정합성)·후보별로 한 조각씩 나눠, 한 응답 안에서 Agent 도구를 여러 번 호출한다.
- 서브에게는 「무엇을 찾고, 결과를 어떤 형식으로 요약해 돌려줄지」를 분명히 준다.
- A의 결과가 B에 필요하면 순차로 한다. 단순 질문·사소한 단일 수정엔 쓰지 않는다.
