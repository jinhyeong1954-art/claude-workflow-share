발송·제출 직전에 「의도한 대상 수 = 실제로 매칭된 수」를 확인한다.

**Why:** 「한 명에게만」 보내려던 것이 필터 조건이 느슨해서 여러 명에게 갈 뻔했다. 발송은 되돌릴 수 없다.

**How to apply:**
- 보내기 전에 대상 목록과 건수를 출력해 의도와 비교한다: 「1명 지정 → 매칭 1건」.
- 다르면 보내지 말고 멈춰서 보고한다.
- 이런 확인은 규칙이 아니라 훅·스크립트의 확인 단계로 만든다(`danger_gate.py` 참고).
