# mission — 큰 작업 컨트롤 파일 (산으로 안 가게)

큰 작업이 산으로 가는 3대 원인:
1. 세션이 길어지며 「왜 이렇게 짰나」를 잊는다 (드리프트)
2. 「정답 상태」가 글로 없어 국소 최적화가 쌓인다
3. 중간 검증 없이 깨진 위에 쌓는다

이걸 **파일 하나**로 막는다.

## 경계 — 무엇이 아닌가
- `BACKLOG.md` = 평면 할 일 목록. 미션은 그중 큰 항목 하나를 펼친 것이다.
  - 🔴 **미션을 열면 BACKLOG에 포인터 한 줄을 넣는다.** 닫으면 그 줄을 지운다. 「할일」이라고 부르면 BACKLOG만 읽으므로, 거기 이름이 없는 미션은 불러도 안 나온다.
- `JOURNAL.md` = append-only 역사. 미션은 지금 살아 있는 상태다. 끝나면 JOURNAL에 한 줄로 졸업한다.
- 작은 작업(1~2번 수정)엔 만들지 않는다.

## 위치
- `missions/<작업slug>.md` (자동 로드 아님)

## 4가지 동작

### ① 시작 / 분할 — 두 갈래
**(a) 자율 분할** — 「미션 시작: 〈목표〉」
1. 기존 설계·구조가 있으면 먼저 실측해 링크한다(추측 금지).
2. 목표를 **검증 가능한 덩어리**로 나눈다 — 각 덩어리에 완료기준(DoD) + 의존성 + 검증 방법.
3. 아래 양식으로 파일을 만들고 BACKLOG에 포인터 한 줄.

**(b) 인테이크 폼** — 「미션 시작 폼으로」 (진짜 목적·제약이 사용자 머릿속에 있을 때)
1. 아래 폼을 **Claude가 아는 칸 = 초안, 사용자만 아는 칸 = `[채워주세요]`**로 채워 보여준다. 작업은 시작하지 않는다.
2. 사용자가 채워 돌려주면 금지선·모순만 점검하고 (a)의 2~3으로 넘어간다.
- 🎓 효용: 빈 종이 대신 절반 채운 폼 → 사용자는 자기만 아는 것만 보탠다.

### ② 열기 / 재개
- **미션 파일 하나만** 읽는다. 앵커 + 현재 위치 + 결정 로그 + 다음 브리핑으로 「3일 전 나와 같은 머리」로 이어간다.
- 전체 역사는 읽지 않는다. 필요한 조각만 그때 연다.

### ③ 갱신 (작업 중)
- 덩어리 상태를 바꾸고(⬜→🔄→✅/⛔) 현재 위치를 옮기고, **새 결정은 「결정과 왜」에 즉시 한 줄.** 그때 안 적으면 다음 세션이 또 헤맨다.

### ④ 닫기 / 체크포인트
- 끝난 덩어리는 **검증 후에만** ✅. 다음 세션 브리핑 갱신.
- 🔴 갱신은 별도 의식 말고 커밋에 묶는다. 안 묶으면 미션 파일이 옛 계획서처럼 썩는다.
- 전체 완료: BACKLOG 줄 삭제 + JOURNAL 졸업 한 줄 + `missions/_done/`로 이동.

## 미션 파일 양식
```markdown
# 🎯 미션: <작업명>
> 생성 <날짜> · 상태 ⬜대기|🔄진행|✅완료|⏸️보류
> 부르는 법: "미션 <작업명>" → 이 파일만 읽고 현재 덩어리부터 이어감.

## 🎯 목적 (왜)
<없애려는 문제 1~2줄>

## ⚓ 앵커 (정답 상태 — 링크만)
- 설계/구조: <문서 경로>
- 🔴 불변식: <절대 깨면 안 되는 것>

## 🧩 작업 분할
| 상태 | 덩어리 | 완료기준(DoD) | 의존성 | 검증 |
|------|--------|---------------|--------|------|
| ⬜ | A. <…> | <무엇이 되면 끝> | - | <확인 방법> |
| ⬜ | B. <…> | <…> | A | <…> |

## 📍 현재 위치
<한 줄>

## 🧠 결정과 왜
- <날짜> <무엇을 이렇게 정함> ← 왜: <한 줄>

## ▶️ 다음 세션 브리핑
- 시작점: <어느 덩어리부터>
- 필요한 것: <읽을 파일 — 딱 이것만>
- 손대지 말 것: <…>

## ⚠️ 수용한 위험 / 지금 안 짓는 것
- <…>
```

## 인테이크 폼 양식
```markdown
# 📝 미션 인테이크: <작업명>   (채워서 "이걸로 시작"으로 주세요)
## 1. 🎯 진짜 목적 (없애려는 고통)   <Claude 초안>
## 2. ✅ 성공의 모습   [채워주세요]
## 3. 👤 누가 / 어떻게 쓰나   [채워주세요]
## 4. 🔴 절대 깨면 안 되는 것   <Claude 초안 — 보태기>
## 5. ⚓ 관련 기존 코드·설계   <Claude 실측 초안>
## 6. 🧩 큰 덩어리 초안   <Claude 초안 A→B→C>
## 7. 📦 이번에 하는 것 / 일부러 안 하는 것   <Claude 초안>
## 8. ⏱️ 우선순위 · 기간   [채워주세요]
## 9. ❓ Claude가 막힌 질문   <1~3개>
```

## 보고
만든·연·갱신한 미션 파일 경로 + 덩어리 상태 요약(✅n/총n) + 현재 위치 한 줄. 끝은 평서문.
