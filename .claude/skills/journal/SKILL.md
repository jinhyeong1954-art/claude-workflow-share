# journal — 작업로그 → 저널 통합

터미널 창을 여러 개 띄워 일하면 각 세션이 `memory/_inbox/`에 작업로그를 남긴다. 이걸 `memory/JOURNAL.md`로 합친다.

## 절차

### ① 수집
- `memory/_inbox/*.md`를 읽는다. `README.md`와 `_done/` 폴더는 제외.
- 같은 작업의 여러 로그는 실제 내용으로 묶는다.

### ② JOURNAL 통합
- `JOURNAL.md` **맨 위에 새 블록 추가**(최신이 맨 위, 과거 블록은 건드리지 않는다).
- 형식: `## 세션 #N — 날짜 · 제목` + 상황 / 한 일 / 확정 결정 / 배운 점 / 다음.
- 🪶 **한 블록 약 25줄 상한.** 세부는 메모리 파일로, 저널은 요지만.

### ③ 아카이브 점검
- JOURNAL이 약 40블록·800줄을 넘으면 오래된 절반을 `JOURNAL_ARCHIVE.md`로 옮긴다.

### ④ 합친 파일 이동
- 통합한 로그는 `_inbox/_done/`으로 옮긴다(삭제 아님). 그래야 다음 정리 때 같은 걸 또 합치지 않는다.

## 범위
- 로그 → 저널 통합만 한다. 메모리 갱신·커밋은 하지 않는다(시키지 않은 것까지 끌어오지 않는다).

## 보고
통합한 블록 수 + 옮긴 파일 수 + 아카이브 여부를 한 줄로.
