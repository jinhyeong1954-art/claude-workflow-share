# 🎯 미션: 보고서-자동화 (예시)
> 생성 2026-01-10 · 상태 🔄진행
> 부르는 법: "미션 보고서-자동화" → 이 파일만 읽고 현재 덩어리부터 이어감.

## 🎯 목적 (왜)
매달 엑셀 3개를 손으로 합쳐 보고서를 만드는 데 반나절이 든다. 이걸 클릭 한 번으로 줄인다.

## ⚓ 앵커
- 원본 위치: `data/raw/` (읽기만, 절대 수정 금지)
- 🔴 불변식: 원본 엑셀 0손상 · 합계는 손 계산본과 1원도 안 달라야 함

## 🧩 작업 분할
| 상태 | 덩어리 | 완료기준(DoD) | 의존성 | 검증 |
|------|--------|---------------|--------|------|
| ✅ | A. 원본 3개 읽기 | 행수·합계가 원본과 일치 | - | 대조 스크립트 |
| ✅ | B. 합치기 | 지난달 손 작업본과 셀 단위 일치 | A | 비교 결과 0건 |
| 🔄 | C. 보고서 서식 | 지난달 보고서와 같은 모양 | B | 눈으로 확인 |
| ⬜ | D. 더블클릭 실행 | 비개발자가 클릭 한 번으로 생성 | C | 실사용자 시연 |

## 📍 현재 위치
C 덩어리 — 표 서식까지 완료, 차트 남음.

## 🧠 결정과 왜
- 01-10 원본은 복사본으로 작업 ← 왜: 원본 0손상이 불변식
- 01-11 차트는 v1에서 뺌 ← 왜: 보고받는 쪽이 표만 본다고 확인

## ▶️ 다음 세션 브리핑
- 시작점: C의 머리글 서식
- 필요한 것: 지난달 보고서 1개만
- 손대지 말 것: `data/raw/`

## ⚠️ 수용한 위험 / 지금 안 짓는 것
- 원본 양식이 바뀌면 A를 다시 손봐야 함(연 1회 정도라 수용)
- 안 지은 것: 자동 메일 발송·차트
